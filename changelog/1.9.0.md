# Simple Citations 1.9.0

## Fixes

- **Pandoc export and PDF image export could silently fail on 1.8.0.** The
  1.8.0 cleanup switched the Node built-in loader to dynamic `import()`, which
  throws in Obsidian's renderer. Both commands now load `child_process` / `fs`
  / `path` with `require()` again.

## Improvements

### Sample template
- New **Sample template** setting under **Note content → Additional content**:
  pick a built-in Bases view — *Same first author*, *Same journal*, or both —
  and it is inserted at the top of every literature note. Each sample is an
  embedded `base` block that reads `this`, so there is no template file to
  create or maintain. A configured **Template file** still takes precedence.

### Pandoc and Poppler path detection
- External tools are now launched with a widened `PATH` (Homebrew, MacPorts,
  conda/mamba, `~/.local/bin`, the standard Windows folders, …), so **Pandoc
  Citeproc Execution (docx)** and **Export PDF images** work even when Obsidian
  was started from Finder / Dock / GNOME and did not inherit the shell's
  `PATH`. In most setups **no path needs to be configured any more.**
- Each field shows a live status: a green check with *"Auto-detected on PATH —
  no path needed"* when the command already resolves, or a red cross with a
  hint when it does not.
- New **Detect** button: searches the common install locations, then asks your
  login shell (`command -v`, `$PATH`; `where.exe` on Windows) — covering tools
  added in `.zshrc` / `.bashrc` — and fills in the absolute path.
- Detection failures are logged to the developer console with a full trace of
  every location checked.
- Works on macOS, Linux and Windows. The fields are hidden on mobile, where
  these features are unavailable.

### Export folder
- New **Detect** button next to **Export folder**: fills in your Downloads
  folder in one click. It follows the XDG user-dirs config on Linux and the
  registry known-folder location on Windows, so a relocated Downloads folder is
  still found.
- The field now shows a live green check / red cross for whether the configured
  path is an existing directory.
