# Simple Citations 1.11.0

## Improvements

### Created date property
- New **Created date property** setting under **Note content → Additional
  properties**. Enter a property name (e.g. `date`) to store each literature
  note's creation date as `YYYY-MM-DD`, Obsidian's date property format.
- The date comes from the note file's creation time. An existing value is
  never overwritten, so a full sync keeps the original date.
- Leave the setting empty (the default) to disable it.

### Sample templates
- The built-in **Same first author** and **Same journal** Bases views now show
  up to 10 notes instead of 20. Existing notes pick up the new limit the next
  time they are updated.
- A blank line is now inserted above `<!-- END_TEMPLATE -->` in each
  literature note.
