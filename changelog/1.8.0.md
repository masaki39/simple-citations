# Simple Citations 1.8.0

## Breaking

- **Minimum Obsidian version is now 1.13.0.** The settings tab was rebuilt on
  Obsidian's declarative settings API (`getSettingDefinitions`), which is only
  available from 1.13.0. Users on older versions stay on 1.7.0.

## Improvements

### Settings tab
- Rebuilt declaratively, so every setting now appears in Obsidian's settings
  search (**Settings → search**).
- Bibliography files are managed as a proper list with drag-to-reorder and a
  delete button per row.
- Behaviour change: after editing **Optional fields** or a bibliography file
  path, the dependent rows (custom merge strategies, BetterBibTeX toggles)
  refresh when the field loses focus rather than on every keystroke.

### Plugin guideline cleanup
- Replaced lazy `require()` calls with `await import()` for Node built-ins in
  the Pandoc and PDF commands.
- Dropped informational `console.log` calls; skipped-citekey diagnostics are
  now `console.warn`.
- Replaced the deprecated `setWarning()` button style with
  `setDestructive().setCta()`.
