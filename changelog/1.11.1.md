# Simple Citations 1.11.1

## Improvements

### Created date property comes first
- The property set in **Created date property** (e.g. `date`) is now placed
  at the top of each literature note's frontmatter instead of after the
  plugin's other properties.
- Notes where 1.11.0 already added it at the bottom have it moved to the top
  the next time they are updated. The existing date value is kept.
