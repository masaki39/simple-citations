# Simple Citations 1.7.0

## New Features

### Set citation style from the Zotero style repository
- New command **Set citation style (csl property)**.
- Fetches the full style list from the [Zotero style repository](https://www.zotero.org/styles) and lets you search it with a fuzzy finder.
- Writes the selected style URL (e.g. `https://www.zotero.org/styles/apa`) to the `csl` frontmatter property of the active note.
- Pandoc picks up the `csl` property automatically, so the next **Pandoc Citeproc Execution (docx)** run uses the selected style.
- Works on all platforms; the style list is fetched via Obsidian's request API (no `curl`, `jq`, or `fzf` required) and cached for the session.
